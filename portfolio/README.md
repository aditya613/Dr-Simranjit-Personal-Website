# Dr. Simranjit Singh — Academic Portfolio Website

This folder contains the Next.js 16 web application for **Dr. Simranjit Singh's** personal academic website.

For full project documentation, design philosophy, and screenshots, please visit the [Main Repository README](../README.md).

## Quick Start

```bash
# 1. Install dependencies
npm install

# 2. Run local development server
npm run dev

# 3. Build for production
npm run build
```

Open [http://localhost:3000](http://localhost:3000) to view the application.

## Technologies Used

- **Next.js 16** (App Router)
- **React 19**
- **TypeScript**
- **Tailwind CSS v4** + Custom Design Tokens in `app/globals.css`
- **Motion** (`motion/react`)
- **Phosphor Icons** (`@phosphor-icons/react`)
